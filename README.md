# Apparel Support Copilot

An assistant that classifies apparel customer support tickets, answers from the brand's policies, and takes simple actions, with confidence thresholds and human handoff.

## Docs

- [Problem brief](docs/problem_brief.md): what we're building, why, and how we'll measure it
- [Labeling guidelines](docs/labeling_guidelines.md): what each intent means

## Setup

```bash
make setup   # install dependencies and git hooks
make help    # list all commands
```
